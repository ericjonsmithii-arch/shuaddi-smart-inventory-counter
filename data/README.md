# Data

## Planned Data Sources

This project will use a combination of publicly available object detection datasets and self-collected images of sHū addi apparel products.

### Public Dataset

- Roboflow Universe: https://universe.roboflow.com/

### Self-Collected Images

- Hats
- Shirts
- Socks

### Estimated Dataset Size

Approximately 300–500 images.

### Labels

The object classes for this project are:

- Hat
- Shirt
- Socks

Public datasets may already include labels. Any self-collected images will be labeled using Roboflow if additional training is needed.
